# Install and run your first target search

Follow the bundled [installation and first-use recipe](../README.md#install-from-a-source-checkout): bootstrap the application checkout, package/install its VSIX, configure absolute CLI/Node paths in trusted User Settings, then open the separate target repository.

Run **PairOfCleats: Select Repository**, **Show Effective Settings**, **Index Build**, **Index Validate**, then **Search**. Pick a known target term and open its source result. The PairOfCleats Output channel and **Inspect Tasks** expose diagnostics and exact operation ownership. No global CLI link is required.

For filter-only browsing, bounded continuation, saved evidence and execution-host limits, see the bundled [user guide](../README.md#search-navigation-and-evidence).
