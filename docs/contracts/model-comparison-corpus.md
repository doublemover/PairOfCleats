# Actual-result corpus admission

Model-comparison report3 binds every mode/query to the generation observed by
that real search child. It validates the exact active root, canonical signature,
build/profile/surface and generation key before resolving the existing source/
chunking corpus identity. Preflight current roots supply no corpus authority.
Different embedding models or build IDs may share a source corpus; missing,
retired or changed actual evidence yields incomparable null quality metrics and
excluded comparable-query denominators.

The existing execution registry remains authoritative for execution fidelity.
A separate compact source-corpus registry interns at most256 actual generations
and512KiB per model. Per-query references retain the mode and original execution
generation. Unchanged generations do not rescan chunk metadata per query. Reported
metadata bytes cover verified index-state reads only; chunk-table bytes and heap
peaks remain unobserved. Retention or admission limits yield explicit unknown
corpora, with no preflight fallback or gain claim. Unresolved contained-reader
ownership errors propagate before ordinary incomparable diagnostics.
