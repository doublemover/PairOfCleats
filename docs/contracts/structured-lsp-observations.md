# Structured LSP observations

Implementation status: UNVALIDATED. All fixtures are authored and unrun. This is not a real-tool or published-generation qualification receipt.

The shared collector declares navigation, symbol-detail or hierarchy-detail consumers before acquisition. It records immutable source/session/profile/context/generation identity, raw protocol payload and operation-specific facts. Definitions and type definitions retain Location versus LocationLink, origin selection, target selection and target container ranges. References retain their request declaration policy. Hierarchical DocumentSymbol parents remain distinct from SymbolInformation container-name presentation. UTF-8/16/32 positions use the existing exact mapping owner; external or unmapped targets remain explicit.

The legacy LSP pass records the raw document-symbol and location responses it already requested. Legacy signature caches cannot satisfy these observations. The build-owned LSP session writes bounded immutable evidence sidecars and canonical evidence records, joined to an unambiguous admitted declaration only with an `evidenceInput` edge. These records preserve observations and do not create syntax partitions, type structure, complete dispatch targets or subtype closure. Selected-target policies retain their existing definition collector; broad symbol evidence is suppressed for those policies.

The canonical detail service exposes retained evidence records. `readLspObservationDetail` verifies the sidecar hash, canonical source and generation before returning the structured detail and source-qualified navigation candidates. Consumers must join candidates to their pinned source witnesses before navigation. A received response scopes coverage to the requested question; unknown project readiness remains partial.

Captured same-source target ranges also pass the existing retained source verifier's streaming UTF-16 scalar-boundary check. Splitting an emoji's surrogate pair is rejected even when both numeric offsets are in range. Foreign-source coordinates remain provider observations requiring a separate pinned-source join; this check does not upgrade them to navigation authority. The authored scalar-span regression remains unrun.

The shared exact-coordinate producer also rejects a UTF-16 range that splits a scalar before an observation is written. Such a target remains `invalid_range` with no exact span; a protocol position roundtrip cannot upgrade it. This producer meaning is covered by the shared LSP binding version, including the source-pinned SCIP adapter's coordinate identity.

Hierarchy methods are capability-gated and opt-in in the shared capability/request-budget owners. Opaque items stay within one source/session/profile collector. The collector caps requests, facts, bytes, depth and elapsed time; repeated hierarchy items reuse scoped observations, avoiding cyclic request loops. The existing LSP transport/guard remains responsible for timeout cancellation and child lifetime. No default hierarchy sweep, server installation or project execution is added. Language-specific hierarchy launch profiles and two real-provider qualifications remain pending.

The existing diagnostics collector now retains notification version, owned version, explicit unknown version and truncation metadata. Missing notifications remain unobserved; stale versions are rejected by the existing owned-document check. Diagnostics persistence/consumer wiring beyond this metadata API remains pending.
