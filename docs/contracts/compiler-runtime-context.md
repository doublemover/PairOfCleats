# Compiler runtime context

The compiler's value slice, CFG, implicit accessor collector and binding invocation handoff share a memoized runtime-context owner. Type queries still resolve value declarations for binding purposes, but their identifiers do not evaluate those values, capture them into function-type syntax or perform runtime calls. Type aliases, interfaces, type parameters, ordinary annotations/type arguments, ambient declarations and TypeScript's explicit `this` parameter are erased from these runtime consumers. Import/export binding syntax remains available to the binding owner without becoming a value-slice read.

Class heritage needs a distinct rule: a class `extends` expression evaluates its base, while `implements` and interface heritage do not. The runtime base and computed class/object names keep their existing evaluation and capture ownership. Parameter defaults, shorthand property values, expression wrappers and method bodies retain runtime value reads. Static property names, declaration/binding names, labels, plain assignment targets, iteration targets and deleted identifier references do not borrow a lexical value-read role.

The canonical syntax inventory and binding/type-name references are preserved. The compiler binding producer advances for removed erased invocation admissions; CFG and value-slice producers advance for changed emitted operations, reads and captures. The call-summary algorithm is unchanged and consumes the corrected producer inputs. This context owner is a syntax admission rule, not a complete TypeScript emit interpreter or a proof of call, heap, decorator, suspension or runtime closure. General control-flow reachability and language-specific emit effects retain their existing uncertainty.

Authored regressions inspect real compiler syntax, immutable read/capture rows, direct CFGs, implicit getter candidates and the actual compiler-session handoff with the fixture's real Program. They cover type queries/signatures, interface and ambient computed keys, class/interface heritage, explicit `this`, defaults, wrappers and shorthand/runtime method reads. All remain **UNVALIDATED**: no tests, syntax, lint, format, bootstrap, compiler/native/source execution or benchmarks were run.
