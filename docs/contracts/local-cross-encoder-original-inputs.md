# Original local cross-encoder inputs

The local scorer captures the original tokenizer encode/call and native session
run callbacks and their receivers before its first source await. It captures a
dense own-data BERT input-name list once, including required input IDs/attention
mask and an optional token-type row. Duplicate or unknown input names cannot
change a later member's native feeds. Selected generation/mode/repository scope
are request data captured before source loading. Later runtime/context field
replacement cannot supply another callback or source identity.
The actual local adapter captures these runtime operations immediately after
original session adoption and retains them across its serialized requests. Later
artifact verification or native method-field replacement cannot substitute the
operations on an already published adapter. Direct scorer calls capture their
supplied runtime once at request admission.
Only the exact private captured runtime producer bound to those same original
tokenizer/session objects may be reused. Copied facade fields, matching callback
identity, a sibling session or a falsey lookalike cannot authorize its operations.

Query and pair token rows must be dense own passive integer arrays within the
existing profile allowances. Mask/type values remain binary. The scorer copies
validated primitive tokens once and constructs native int64 data from those
captured values. Custom row predicates/iterators, missing slots, inherited fields
and accessors cannot bypass admission or inject native token values. Every pair
row is admitted before allocating its input tensors. Original inspection errors
propagate with their existing independent ownership; actual adapter/session
cleanup continues to use its existing original failure and queue owners.

Returned authoritative source fields are captured once as own passive data
before generation/span/UTF-16/digest/character checks and pair formatting. A
source getter cannot replace the passage between those checks. This adds no
source fallback, model selection, artifact pin, license/revision claim, profile
allowance, truncation or quality promotion. Canonical producer provenance and
the caller's captured candidate membership remain separate prerequisites.

Actual scorer/input/output/tensor-owner controls are authored but **UNVALIDATED**.
No tests, syntax/lint/format, bootstrap, native/model/child/IPC, browser/editor/GPU,
build or benchmark execution occurred. Supported real tokenizer/runtime array
shapes, model compatibility, native lifetime/retry safety and resource/quality/
performance acceptance remain separately scoped.
