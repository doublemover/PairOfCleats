# Provisioning failure and returned-resource observation

Status: **UNVALIDATED source and authored regressions**. No fixture, syntax,
format, bootstrap, installer, executable or native process has run for this batch.

Prerequisite byte admission and probe reporting capture the original ownership
predicate and receiver before reading diagnostic fields. An observer remains
binding when the pending flag is absent or false. Missing observers on marked
pending failures, unreadable lifecycle properties and throwing observers remain
unknown; classification cannot turn them into an actionable missing command.

An unsettled original is retained through the shared storage error-context
owner, together with the captured predicate. A replacement getter or function
therefore cannot authorize another probe or a successful verification. This is
an additional blocker, not a settlement, retry, process termination, installation
lease or cleanup capability. No PID, parent discovery or cause scan supplies
authority. Resource reconciliation remains with the actual original producer.

Code, name, result and bounded output classification reads are protected. A
getter failure retains both the original failure and exact secondary, including
null, undefined, false, zero and an empty string. Original observer errors are
retained independently. Ordinary unmarked primitive failures still become the
existing missing-byte/spawn-error reports rather than a TypeError in the catch.
Known settled timeout/missing/spawn reports retain their existing vocabulary.

Fulfilled shared child results and caller-supplied synchronous/asynchronous probe
results receive the same original-resource guard before verification and before
reading executable bytes again. Report/verification getter failures retain the
actual original result and its independent inspection error. The captured
predicate is checked again after classification. The private observation-failure
brand only prevents reclassification of actual producer diagnostics; matching
fields cannot forge that brand and it grants no release authority. Retained
outward ownership methods are immutable, and original objects stay in their
exact cause/errors graph rather than having their observers replaced in place.
Post-probe identity or cancellation failure keeps its actionable primary message
and also retains the original returned resource and captured predicate.

That invalid boundary retains unknown work rather than starting another probe
or recognizing a runtime from it. Existing physical executable identity checks,
typed runtime acceptance, bounded child transport and cancellation paths remain
the owners of their respective guarantees.
