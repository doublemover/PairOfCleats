# Lexical source boundaries and replay

Lua fallback declarations retain the parameter-closing source coordinate and
scan executable bytes beginning there, including the first physical line.
Nested named and anonymous callable ranges belong to their own owner. Strings,
long strings and comments retain their original offsets while their contents
are masked for calls. This route remains explicitly partial lexical evidence;
native call facts retain their separate syntax-owned route. Real self-calls
remain calls. Call-flow producer 53 and source-chunking producer 52 invalidate
the previous meaning through the canonical analysis-policy owner.

Python and Starlark share delimiter termination, including escape parity before
ordinary and triple quotes. The reader neither evaluates nor decodes literals;
language-specific consumers retain prefixes, literal values, budgets and
argument roles. Raw literals still escape quotes for delimiter recognition.

Python's lightweight import identifier profile is Python 3.15/UCD 17.0, using
Unicode ID properties with NFKC closure. Another Node Unicode database is
unsupported by this profile. Raw module/member/alias spellings and logical
statement source envelopes remain separate from normalized semantic names;
Unicode filenames are not globally normalized. Relative dots remain separate
from identifier segments. The collector retains its unqualified lexical import
receipt and refresh-required policy, including on empty output. It gains no
complete Python parser or binding claim.

The existing import-resolution producer changes from 26 to 27. Its current scan
fingerprint is shared across languages, so this intentionally conservatively
invalidates import caches beyond Python/Starlark. There is no second local
producer identity or admission exception for old entries. Persisted lexical
entries still refresh rather than receiving parser authority.

Both XML structural routes pass through one source-gap owner. Native elements
retain their exact structural range; uncovered document bytes receive separate
envelope chunks. Prologs, inert declarations, processing instructions and trailing
content are represented once per gap, without widening nested elements or
resolving entities. Limits may split source ownership while preserving its
original parent metadata. Source-chunking producer 52 retires missing-prefix
meaning. Native and lexical qualification require separate actual consumers.

Go type roles unwrap only grammar-defined parenthesized types. Wrapper work is
linear in wrapper depth; slice, map, pointer, function and field/result roles are
not transparent. Native chunk producer 17 retires earlier kind/name projections.

Python indexes LF, CRLF and bare CR into the original JavaScript string. CPython
tokenization uses universal physical rows while byte-column conversion and IDs
retain original offsets. No normalized source copy supplies hashes or ranges.
Inline import suites are recognized only after a compound-header colon outside
brackets and lambda expressions; arbitrary colon-bearing expressions are not
searched for dependency-looking substrings. This extends the same partial import
producer 27 without adding a complete-language claim.

Bash static words retain internal hashes and quoted/escaped suffixes. Unquoted
globs and expansions remain unresolved. Resolver engine v9 treats admitted shell
paths as file literals while JS/HTML URL suffixes and Node package aliases retain
their existing normalization rules. Import producer 27 invalidates old omissions.

YAML top-level mode always obtains document extents from the canonical YAML
syntax owner. Successful optional native pairs attach with their own untouched
ranges inside those extents; sequence/scalar/empty documents retain independent
envelopes. The native route therefore includes canonical document parsing cost.
Root mode deliberately takes precedence over native structural subdivision;
workflow handling remains its separate canonical route. An unavailable or empty
native structure is labeled explicitly and cannot qualify native success.
