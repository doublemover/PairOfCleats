# Source-linked schema evidence

Implementation status: UNVALIDATED. Source and focused regressions are authored; no GraphQL library invocation, fixture, formatter, gate or published-consumer qualification was run for this change. Issue #1191 remains partial.

`collectGraphqlLinkedEvidence` takes an explicit partition of already admitted local snapshots into schema and executable-document paths. The current adapter profile accepts the existing application GraphQL.js **16.12.0** dependency. Its schema construction, schema validation, operation/fragment validation and `TypeInfo` traversal resolve type, field, argument, directive, enum-value and fragment references to exact original source spans. Built-ins without a local source declaration, unknown fields and missing/duplicate fragments retain unresolved states. Schema errors prevent schema-linked projection. Invalid operations retain diagnostics and any individually qualified source references. Original preambles and UTF-16 spans are preserved. No import is fetched and no resolver, project configuration module or remote introspection is executed.

Inputs are limited to 20 documents and 500 KiB. AST nodes, nesting, tokens, references, diagnostics and elapsed work have separate bounds; cancellation is checked between bounded synchronous library operations. This is not preemptive cancellation inside GraphQL.js. Config, dependency, source, generation and runtime-version identities contribute to a content-addressed report. A supplied profile hash is retained provenance; app-library loading is still explicitly `application-library-unqualified` because its complete observed module closure has not been integrated. Every current result stays partial, and no compiler type/call/binding coverage is claimed.

Adapter version `2` applies [complete-report byte admission](source-linked-report-bounds.md) before returning evidence. The existing GraphQL declaration's 500 KiB allowance includes repeated target witnesses and the content identity; a small valid source can still exceed that output allowance. The same finalization owner covers the JSON-reference adapter's existing 1 MiB ceiling.

`writeSourceLinkedEvidence` independently applies its existing complete-report byte allowance during canonical capture, including for reports supplied outside an adapter finalizer. It checks the full report identity, original source bytes, immutable parser partition hashes and current generation before using the existing immutable sidecar/analysis writers. Oversized reports retain `ERR_SOURCE_LINKED_EVIDENCE`; cancellation and malformed JSON remain distinct failures. It returns the existing canonical provider envelope to the common durable sink from #1145. There is no separate semantic database. The sidecar retains the entire bounded dependency/report closure and host-selected source partition inventory and still has its own envelope/storage admission. The retained canonical rows are evidence records; this path cannot replace parser declarations or invent resolver/generated-runtime flow.

`readSourceLinkedEvidenceDetail` hydrates the immutable report from a canonical evidence ref and verifies its source and generation. Cross-source navigation additionally requires an explicitly supplied semantic store from the same generation; it verifies each target manifest, repository namespace, source hash and exact range before returning a navigation candidate. Missing target stores and response limits remain visible in partial/omission fields. The same writer and detail consumer accept the local JSON Pointer subset through `createJsonReferenceEvidenceReport`.

Source verification checks UTF-16 span endpoints while streaming the retained UTF-8 bytes, including scalars split across physical read chunks. Source observations, inline diagnostic ranges and all requested target ranges must preserve scalar boundaries. Target ranges for one source are checked together; verifying its first range does not qualify later ranges automatically. The public compact evidence reader reuses only already checked endpoints and charges any additional physical source verification to its existing page byte allowance. The authored `indexing/semantic/retained-evidence-scalar-spans` regression is unrun.
