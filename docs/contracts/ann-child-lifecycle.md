# ANN child lifecycle

An isolated Stage-3 HNSW or LanceDB build submits at most three sequential channel jobs to the existing asynchronous subprocess supervisor. One child imports the backend once, checks bootstrap readiness and consumes a bounded 64 KiB metadata-only request. Vectors stay in manifested artifacts; vector arrays are forbidden in this handoff. Child lifetime ends with this backend invocation. No native worker or served handle is retained across builds.

The protocol records a target start before native execution and a terminal receipt afterward. Independent ordinary writer errors are recorded and the same child proceeds to its next channel. A native crash preserves completed receipts, marks the active target unavailable and starts only unstarted siblings in a fresh child. Started jobs are never retried. Startup failure without an identified active target fails the unresolved inventory. Invalid, duplicated or partial protocol records cannot authorize output from that child. There is no implicit parent-process fallback after an isolated native crash.

The supervisor owns cancellation, process-tree termination, bounded stderr and actual close evidence. If it reports pending child ownership, the exact error and release witness propagate. Stage 3 retains that attempt's unique staging directory and reports its path; a later attempt receives a different directory. Ordinary cleanup runs outside the canceled production admission queue and preserves primary and cleanup failures. Existing backend-generation publication still validates each complete output pair before publishing any manifest entries.

Native graph/table construction now acquires CPU and memory tokens from the existing embedding compute queue, with an estimated byte charge. HNSW, LanceDB and variants remain serial by default. The byte estimate is admission accounting, not a measured native RSS ceiling or a qualification of each library's internal thread count. Controlled overlap, worker persistence and revised resource thresholds require later native measurements.

Backend results and `index_state.extensions.annBuildWork` record child starts, terminal variant records and crashed variants. Diagnostic failures retain immutable evidence returned by the existing crash logger. The authored inert-transport fixture covers one-child startup amortization, fragmented records, crash attribution, unstarted sibling execution, protocol refusal and unreaped cancellation ownership. Actual child/native failure, wall/CPU time, event-loop delay, setup cost and peak-RSS comparisons remain unrun.
