# Prepared semantic row and final-index encoding

Semantic producers supply their existing per-batch byte allowance before canonical encoding, snapshotting and freezing. JavaScript, TypeScript, native syntax, derived analysis and ownership use the shared prepared-entry owner. The sink independently checks schema, row/sequence limits and the producer byteCount before any write. A private WeakMap identifies actual immutable snapshots; caller strings, copied objects and encoded-looking fields grant no shortcut. Bounded encoding rejects oversized leaves before escape allocation. Ordinary syntax producers retain ERR_SEMANTIC_RECORD_LIMIT; derived analysis/ownership retain ERR_SEMANTIC_CONTRACT. Only actual bounded-encoder failures are remapped; foreign failures with matching codes remain original.

The partition sink reuses the verified canonical row string for payload buffers, offsets and hashes. A complete prepared batch plus one producer lookahead remain bounded by the existing row/byte envelopes. These bounds do not include the original source, parser AST or caller-owned input. Strings are immutable and parsed snapshots are deeply frozen. No public format, budget or configuration surface changes.

The query and operation index writer encodes each final row once, retaining its canonical line, newline-inclusive UTF8 length and independently parsed key/previous-row snapshot. Awaited flushes and a pull producer reusing objects cannot change admitted bytes, first/last keys or ordering witnesses. At most one existing bounded final batch plus one bounded lookahead line is retained; counters describe UTF8 representation bytes, not total V8 heap. Duplicate/order checks, offsets, hashes, fsync, original resource cleanup and disk credits remain mandatory. Intake and intermediate external-sort passes legitimately encode their own projections; the one-pass claim applies only to each final output row.

The existing pieceAssembly producer advances5→6 so old derived assembly cannot silently reuse the changed ownership behavior. Canonical completed partition facts and public artifact format versions are unchanged.

Timings and sampled heap are reported with their limits; reduced serializer work is not a general latency or whole-process memory claim.
