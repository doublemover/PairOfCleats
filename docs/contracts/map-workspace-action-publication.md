# Workspace action publication

Saved-file opening, queries, semantic detail and artifact loading share one
private publication epoch. Starting a newer action, explicit cancellation or
pagehide revokes earlier remaining view/notice authority. File completion cannot
replace a later query while that query is pending. An older failure cannot
overwrite a newer successful view or notice. The previous admitted evidence
remains until a current result passes projection admission.

Semantic/artifact action buttons additionally retain their original projection
and node object. A removed old button cannot submit against a replacement page
or generation. Original relationships, source identity and server-generation
checks remain with the existing request/projection owners.

Failure results retain exact original thrown values, including falsey or frozen
values. Current notices use one passive diagnostic snapshot; optional message,
name and stack getters are not invoked. Obsolete failures retain their primary
in returned evidence without issuing a new notice. Logical revocation does not
establish native fetch/read cancellation, rollback or reader cleanup success.

Actual DOM-emulated app controls are authored for file/query overlap, stale
failure, cancellation, removed semantic actions and falsey diagnostics. Broad
execution is deferred in the parallel implementation wave; real browser/native
effects, accessibility and interaction timing remain separate qualification.
