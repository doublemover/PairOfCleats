# LSP owned target handoff

Before asynchronous definition work, the retained LSP session captures the selected-target array through passive own-data descriptors on its exact finite target surface. Selection length cannot exceed the immutable non-definition occurrence inventory. The canonical occurrence/expression schemas supply role and invocation enums; fixed spans, same-partition refs and source-owned spelling comparisons prevent arbitrary nested metadata or string expansion during capture. Accessors, sparse/decorated arrays and extra fields fail without reading their values. It rejects duplicate references, foreign syntax partitions, non-occurrences and selections outside the existing source policy. Bounded record reads still independently reconstruct each target's exact reference, span, scope, roles, spelling and invocation from the retained syntax/source. Caller metadata must agree completely before any provider request or evidence write.

The request callback receives its own position object. Each returned response is captured before the next asynchronous request, so later mutation of a prior result cannot change its hashed observation, source-qualified target or persisted protocol evidence. [Canonical evidence byte admission](semantic-json-byte-admission.md) rejects accessors and unsupported JSON values and charges the existing sidecar allowance before later acquisition. Existing provider admission and immutable evidence writers retain their own byte/storage checks; this repair adds no public budget or source fallback.

The existing request-cache contents/policy and location interpretation do not change. The shared retained LSP-binding producer identity must advance because target/response ownership and accepted observations change. Source selection, mapping, provider uncertainty and language/server completeness retain their existing limits. Callback completion still does not establish runtime dispatch or semantic closure.

Source/schema cardinality admission bounds the metadata copied by selection capture. It does not bound source acquisition, caller input allocation, Proxy/engine enumeration internals, aggregate admitted response retention or total source-count-times-span comparison work. Full selection and definition publication still lack a durable streaming/resume protocol; a fixed source universe is not a measured resource or latency guarantee.

Authored actual retained-session regressions cover forged span/name/roles/invocation/ref selections, duplicates/getters/sparse arrays, early source-cardinality/role bounds, unvisited unknown nested metadata, oversized spelling, getter-bearing responses and mutations of caller targets before asynchronous reads, callback positions and earlier response payloads. They inspect persisted binding/call-site identity and original protocol evidence. All are **UNVALIDATED**; no tests, syntax, format, bootstrap, server/compiler/native/source execution or benchmark was run.
