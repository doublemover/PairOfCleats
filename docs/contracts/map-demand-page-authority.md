# Pinned map demand page authority

Local preview demand readers validate the transport envelope against the exact
protocol, snapshot, request, revision and operation before accepting its content.
Manifest available counts and rendered overview aggregates must agree. Cached
pages then preserve those available totals, exact advancing continuation and
generation-local row/file/member addresses. A malformed continuation fails before
cache admission; the reader does not loop, invent a cursor or silently omit rows.

File totals match the pinned manifest. Member pages keep their owning file address
and original member ordinal. Resident discovery also checks the resolved file's
member count and a selected entity's adjacency total across its continuation.
Relationship row addresses refer to the pinned original evidence; source certainty,
endpoint fields and opaque scalar IDs are not reinterpreted by this validation.
An explicitly supported legacy alias can still resolve to the original source ID.

Validated response objects are frozen before cache admission. Geometry, inspector
and layout consumers can make their own view objects but cannot mutate retained
evidence through a page reference. LRU eviction remains reversible and does not
change source queryability or available counts. Validation does not infer current
index health, establish source completeness beyond the admitted artifact, or grant
repository write authority from saved metadata.

These are source implementation contracts with authored, unrun regressions.
Browser/worker host behavior, total heap, latency and source streaming from a
canonical artifact reader remain separate qualification and integration work.
