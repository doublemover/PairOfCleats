# Request-local semantic refinement

Implementation status: UNVALIDATED. The explicit API and source-only fixture are authored and unrun. No query path automatically invokes this API.

An explicit `ephemeral` binding request pins repository, generation and canonical occurrence reference, plus wall/fact/output/retained-source budgets. The host creates an opaque grant for that exact question and an observed complete provider profile under current exact repository trust. A qualified bounded provider must independently declare its supported definition method and profile identity. No provider or unknown dependency closure remains unsupported/denied rather than starting a tooling pass.

The API verifies retained canonical source and live source bytes before and after one definition request, rechecks trust and generation, and projects the response through the shared structured LSP collector. External/unmapped candidates, unknown project readiness, deadlines and failure remain qualified partial states. The returned overlay cites its original generation/source/occurrence and is always ephemeral. The module has no generation writer, control store, enqueue or publication dependency. Durable enrichment remains the existing separate plan/enqueue/drain route; adding a publication field is rejected.

The shared provider transport owns cancellation and teardown. This API passes its combined deadline/caller signal and accepts only qualified bounded providers; it does not detach an in-flight owner or run an unbounded arbitrary callback. Retained source witnesses must match the pinned generation and original bytes. Ordinary find/detail/trace and context assembly remain read-only because they do not call this API.

The fixture `indexing/semantic/request-local-binding-overlay` authors exact grant/source/generation checks, missing-provider behavior, source-cited result and unchanged partition inventory. Provider registration/qualification, explicit public request-surface integration, revoked-trust/timeout/child-lifetime fixtures, request-local cache behavior and bounded latency measurement remain pending.
