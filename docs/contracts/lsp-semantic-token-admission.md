# Semantic token source admission

The existing LSP document type consumer decodes a complete relative token response before using it to classify a declaration. Each five-integer tuple must contain protocol unsigned integers, reference the advertised type legend and use only declared modifier bits. Invalid shape, fractional/coerced/negative fields, overflowing accumulated coordinates or an invalid source span reject the entire response through the existing request-failure diagnostic path. A valid prefix cannot hide a broken delta anchor or a truncated tail. A protocol `null` response remains a successful empty request and supplies no declaration classification.

The actual consumer supplies its captured text, protocol line index and negotiated UTF-8/16/32 encoding to the existing exact range mapper. Token spans must fit one source line with exact scalar boundaries. The client does not negotiate multiline semantic tokens. A line terminator, out-of-document line or character, partial UTF-8 scalar or interior UTF-16 surrogate cannot be clamped into evidence. Coordinate-only decoder callers may omit both text and line index; supplying only one is an error.

Lookup uses half-open token ranges. The first position after a token cannot inherit its class, and a zero-width token cannot classify a declaration. Unknown custom type names remain unclassified. Semantic classes and provider overrides use own properties; names such as `constructor` and `__proto__` cannot resolve through an object prototype. Modifier decoding covers the 31 bits representable by the protocol unsigned integer without wrapping bit 32 to bit zero.

This changes LSP producer admission and requires the shared `lspBindings` identity to advance. Semantic tokens have no signature-only request-cache entries, so this change does not alter the current `rq10` cache policy. Authored regressions cover the actual decoder and document enrichment, adjacent tokens, malformed chains, modifier legends, scalar mappings and null responses. They are **UNVALIDATED**: no fixtures, format, syntax, bootstrap, native/server execution or real-tool qualification was run. Exact token attribution does not establish binding, complete source-language semantics or runtime dispatch.
