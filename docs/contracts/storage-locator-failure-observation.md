Status: UNVALIDATED source and authored controls, 2026-10-22.

before classifying an error as missing or invalid. Original independent resource
observations, including false/absent pending markers, must confirm settlement
before code/message projection. Falsey thrown values become conservative invalid
reports rather than property-access errors. Readonly/frozen diagnostic getter
failures preserve both the primary and independently pending inspection owner.

receipt after a successful locator read remains invalid; only an ordinary missing
initial locator may select the existing empty/default result. A retained actual
locator or receipt descriptor propagates its existing private capability instead
of becoming a plain report. Category selection, managed-child planning and
configuration preview inherit this behavior through their existing actual calls.

introduced, and error reporting never prepares category directories.

through the existing configuration planner/apply owner. It retains positive

and synchronous generation-refusal limits remain unchanged; external teardown is
not a receipt. Configuration/migration coordinator release, parser/native work
