# Local conditional binding identity

The local type heuristic's JavaScript guard profile applies to canonical JavaScript, TypeScript, JSX and TSX language IDs. Other languages keep independent annotations, defaults and local literal inference, without borrowing JavaScript `typeof`, `Array.isArray` or `null` guard semantics. Their language providers retain ownership of richer guards and binding behavior.

Guard binding names use complete Unicode identifier boundaries, including astral code points, dollar signs and joiners. Member names and names following a spaced dot do not become facts about a bare parameter/local with the same suffix. Qualified constructor names preserve their complete Unicode identity. Obvious continuing property, index or call operands do not become a shorter constructor/literal fact. A rejected qualified candidate does not prevent finding a later bare candidate on that same line. `typeof` accepts its actual result words with matching quote delimiters; a longer identifier beginning with `null` is not the null literal.

These remain legacy lexical candidate hints with the existing flow source/confidence. This repair does not establish lexical scope resolution, guard polarity, conditional reachability, global builtin ownership or a complete lexer for strings, comments, regular expressions and compound operands. It does not upgrade a candidate into a canonical binding/type proof. The shared type-normalization producer identity advances because these hints feed retained local metadata and cross-file parameter projection; canonical annotation/type-expression normalization is unchanged.

Authored regressions exercise the actual local consumer and cross-file parameter projection across the four admitted language IDs. They include BMP/astral and qualified identities, namespace/member controls, keyword prefixes, invalid `typeof` words/quotes, continuing operands, later bare candidates, language separation and repeated chunks. All are **UNVALIDATED**; no tests, syntax, lint, format, bootstrap, source/compiler/native/provider execution or benchmarks were run.
