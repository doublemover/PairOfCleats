# Internal change investigation pilot

Development slice for #1505; unvalidated and not a public transport contract.
The pure `deriveInvestigation` entry point consumes admitted old/new snapshots,
explicit change classifications and qualified relations. Canonical semantic
generation identities and source-unit IDs are retained, with UTF-16 spans. It
performs no source reads, inference, execution, persistence or automatic edits.
The caller owns source/hash/span admission and the evidence checker registry.

Signature, visibility, import, body, deletion and addition changes produce source
inspection obligations. Old/new relations remain qualified by their original
world. Incomplete discovery creates a separate closure obligation. Ambiguous
correspondence creates an inspection question. No graph population or ranking
certificate proves complete impact coverage.

The pure CAS reducer separates observation from explicit support admission.
Checker receipt IDs refer to upstream admitted named checks; this internal pilot
does not verify arbitrary user-provided receipt strings and must not be exposed
directly as a trusted public endpoint. Role bundles require exact matching world,
branch, assumptions, predicate/version, arguments and quantifier scope. Bundles
are AND; alternatives are OR. Supporting and refuting evidence coexist as a
conflict. Fresh least-fixed-point grounding retracts invalidated dependencies and
prevents evidence cycles from supporting themselves. Caller closure changes only
the workflow status.

Projection pages retain omitted counts without deleting underlying obligations.
The current API retains state in caller memory and supplies no durable storage,
resource scheduler, authorization, cross-world translation or resume transport.
Root-owned canonical schema/CLI/API/MCP integration, admission adapters, explicit
retention quotas, source revalidation, fork/supersede events and empirical
qualification remain outstanding. The authored fixture is not a passing receipt.
