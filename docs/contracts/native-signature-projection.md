# Native declaration signatures through indexed fields

Successful native chunking takes the grammar-owned body boundary, with the
existing bounded lexical fallback for bodyless/unsupported body fields. Nested
parameter/type braces, comments, quoted punctuation and multiline syntax stay
inside the declaration preview. Its existing 2,000-character source-window bound
remains; declaration source ranges retain the complete admitted bytes.

The JavaScript doc projector prefers its existing source-qualified declaration
record, then the parsed signature supplied by the chunk owner. It runs the legacy
regex only when neither producer supplied a nonblank preview. This preserves a
native header whose quoted parameter contains a closing parenthesis and avoids
rescanning its body as a replacement declaration. This does not upgrade native
signature metadata into JavaScript flow evidence; existing occurrence/flow
admission remains separate. Shared sourceChunking advances 30→31 for the changed
retained signature and field-token meaning.

TypeScript and C/C++ retain their native signature handoffs. C declaration names
follow declarator fields through pointer/parenthesized/function wrappers, keeping
typedef/tagged return names separate. Function prototypes preserve their enclosing
declaration while function-pointer variables, parameter declarations and typedefs
remain distinct roles. Existing production role owners are retained.

`indexing/signatures/native-signature-projection` uses real native query/traversal
routes for JavaScript, TypeScript, C and C++, then registered enrichment, canonical
payload/metadata assembly, signature field tokenization, retrieval metadata and map
symbol consumers. Independent source headers and final parameter tokens remain
positive controls; implementation text, false names and pointer-binding callables
remain negatives. Warm reuse preserves the same products. Existing lexical/native
boundary and C/C++ parenthesized-prototype fixtures retain their assertions and
join the ordered lane. All functional execution remains deferred.
