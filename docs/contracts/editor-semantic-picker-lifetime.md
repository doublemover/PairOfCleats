# Semantic editor picker lifetime

The existing semantic evidence adapter admits only original items from each
issued native picker. Rows and arrays are immutable, and multi-selections must
be dense, distinct members of the offered values. Copied/foreign record, action,
route, type, slot, kind or role choices cannot issue a typed consumer request.
Service capability admission is captured for that workflow; a later mutation
cannot add an operation to its already admitted menu.

The original repository context and selected chunk identifier are captured
before later picker work. Cursor binding is captured before choosing its route
and compared with a fresh original cursor witness afterward. Request generation
and response JSON are captured immutably under the existing 64 KiB encoded-size
limit and an internal 64-level nesting admission. This is not a bound on
pre-serialization transient allocation. Producer generation/source/coverage and
frontier semantics remain authoritative; empty partial evidence never proves
absence of flow.

Detail and continuation views retain their actual newly displayed payload.
Publishing a new response cannot let an older state's payload overwrite it.
Back returns to the preceding captured view, and copying each view uses its
original immutable packet. Failed/missing responses do not adopt another
workflow's latest payload as a new successful response. Every native picker and
consumer/view publication checks the existing keyed operation authority.

Exact source opening retains contained source hash, original UTF-16 span,
opened-document URI/buffer/version and final byte checks. The editor returned by
display must contain that exact qualified document before selection/reveal;
equal text in another editor cannot adopt its witness. New workflows revoke
late original display/consumer publication through the existing operation owner.

The additional registered-command and direct adapter/operation controls are
**UNVALIDATED**. No tests, syntax/lint/format, bootstrap, editor/browser/native/
child execution or quality/resource/performance qualification was run. Typed
public schemas, generation discovery producer and source-mapping capability
remain unchanged. Full host cancellation and native teardown remain separate.
