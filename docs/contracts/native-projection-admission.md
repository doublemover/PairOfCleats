# Native declaration projection admission

Native declaration projection uses one parser-owned work ledger for the outer walk, child and field reads, name searches, scope ancestry, and emitted declaration rows. The existing `maxAstNodes`, `maxAstStack`, and `maxChunkNodes` limits apply before creating child wrappers or growing a frontier. Name-search width and depth also retain their existing local limits. Memoized names and shared ancestor links belong only to the current native tree; they grant no persistent-cache admission authority.

The native query route uses the pinned runtime's public Query API with the retained parser grammar. A query executes only at an already admitted declaration root, with `maxStartDepth: 0`; it does not first materialize all file captures. Query compilation and ordinary execution failures retain the existing diagnostic and traversal fallback. Cancellation and unresolved original resource observations propagate instead of becoming ordinary fallback results.

Exhausted projection returns the existing strict whole-file envelope with explicit `partial-projection-budget:<reason>` call coverage, or the ordinary non-strict fallback. It does not advertise a complete empty call set or start an independent advisory walk with a fresh budget. Admitted native calls retain their original occurrence, owner, role, and UTF-16 source ranges. Canonical call-site serialization and bounded spill/merge retain their existing byte, row, and reader limits.

Lexical packages, modules, and namespaces do not make enclosed functions methods. The method promotion policy requires a semantic type kind, preserving true class, struct, trait, interface, and implementation members. In particular, a braced Perl package retains the FunctionDeclaration role consumed by the existing Perl relation and export owners.

PHP semicolon namespace declarations own following program siblings until the next namespace declaration. A budgeted per-program memo supplies that scope without a per-declaration backward scan; braced namespaces retain their ordinary ancestor ownership.

These producer changes require Tree-sitter chunk version 18 and sourceChunking 53 (superseding 17/52). Syntax-facts identities remain unchanged. Every synchronous and asynchronous chunk-cache read/write supplies the original source extent for the independently enforced persistent-cache admission contract.

The focused consumer fixtures distinguish actual native query execution from merely enabling the option. They compare complete cold/warm query/walk evidence, count original native metadata operations independently, exercise interrupted and rejected admission, and publish actual native occurrences through bounded spill. Resource records label CPU, endpoint memory and process-lifetime OS maximum RSS precisely; they are not continuous per-case peak measurements. Native parsing itself remains governed by its existing input and parser limits and is outside the projection operation count. Broad representative incremental and per-case peak resource acceptance requires separate measured evidence.
