# Retrieval comparison response admission

Parity and model-comparison reports advance to version 2 for these qualification
and nullable-measurement semantics. Historical reports are not rewritten.

Judged evaluation, parity and model comparison share successful-response and
selected-cohort admission. Each requested array must be explicit and dense, with
object hit rows. Missing/null/non-array/failed responses are unavailable. A
present output-budget receipt must prove zero omitted hits; metadata-only
compaction remains admissible. Explicit empty arrays remain valid zero-hit
observations. They are not substituted for missing evidence.

Comparison captures passive stable hit identity and finite score fields before
later work. It does not invoke getters or coerce diagnostic objects into IDs.
Unknown identity stays incomparable. Existing distinct-hit arithmetic and
null-when-undefined common-rank correlation remain. Score-space qualification is
a separate measurement boundary; admitted arrays alone do not prove numerical
score comparability.

Each comparison arm retains its own interned observed execution registry.
Requested versus observed backend, fallback/fidelity and selected generation
remain explicit. SQLite storage aliases retain their actual labels; an FTS claim
also needs observed FTS execution for positive hits. A fallback memory response
cannot certify a SQLite arm. Parity requires the same selected source generation
on both sides; model comparison retains its independent logical corpus guard.

Reports retain every requested query and separate per-cohort availability,
identity qualification, valid zero-hit coverage and positive-hit witnesses.
Invalid selected cohorts cannot erase valid sibling observations. Unavailable
observations do not enter numerical means; missing timing/memory remains null.
Strict parity fails on unavailable/unknown/mismatched/mixed execution or missing
positive cohort witnesses. Those failures are not waived by optional FTS quality
threshold warnings. Invalid responses also make a non-enforced report fail after
it has retained the complete requested result list. The matrix admits only fresh
reports with complete qualified comparison coverage.

Named, explicitly selected canned adapters test report contracts, not native
backend quality. Their fixture profile/reason/signature identify that scope.
Partitioned actual parity-entry cases cover positive/different rankings, explicit
emptiness, malformed/missing/failed cohorts, output omissions, unknown identity,
wrong observed backend and mixed valid/unavailable queries. Shared owner controls
also preserve passive admission and source snapshots. Existing partial-rank
assertions remain; an independent prose control supplies that fixture's required
positive cohort witness.
