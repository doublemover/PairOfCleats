# Source-bound motif analogy pilot

`graph/analogy/source-motifs.js` projects supplied source role/relation facts and
matches deterministic validation/publication, cache-invalidation and shared-target motifs.
It uses exact owned source snapshots, canonical manifest verification and UTF-16
spans. View identity pins generation, repository, build context, role projection,
source roots and all qualified directed relations. Role labels remain supplied
declarations, not inferred behavioral facts. This is an admitted candidate view,
not repository-wide discovery or a replacement graph store.

The retained semantic adapter now acquires selected canonical record refs and
their source snapshots from the pinned artifact store, then pages that store's
existing incident-edge index. It admits only canonical call/construct-target
edges in the requested build context and preserves their exact evidence records,
including conditions and evidence refs. Exact-static/modelled/heuristic certainty
maps to exact-in-model/may/heuristic respectively. No observed-runtime status is
inferred. Other contexts are counted and excluded; source maps require their own
qualified original-source adapter.

A third motif, `shared-call-target/v1`, connects two selected invocation records
to the same retained target. Its result is useful source-linked inspection of
canonical targets and parallel evidence. Argument/effect compatibility, binding
coverage and transfer across build contexts remain explicitly unknown. The
adapter bounds actual incident rows scanned and retained source bytes; exhaustion
leaves a partial view rather than implying absent calls.

This canonical projection also supplies an actual consumer for the checked
occurrence-bag sum owner. Selected incident groups preserve original canonical
edge/support/source IDs. An independent bag-equivalence receipt permits only
unranked sum regrouping; the existing factor cursor enumerates the same witnesses
before motif matching. Ordering and physical choice paths are not equated.
Parallel edges and their conditional evidence survive composition. This is an
explicit bounded correctness route, not a measured optimization.

Required roles are injective. The validate motif retains producer/artifact,
validator/artifact and publisher/artifact relations to the same structural entity;
that alone does not prove the same bytes or successful validation dominates
publication. The cache motif retains dependency/read/invalidation relations;
it cannot infer complete invalidation from a delete-shaped operation. Parallel
relations and their exact-in-model/may/observed qualifiers remain in witnesses.

Search orders smallest role domains first and checks assigned directed relations.
An independent map checker validates every returned role map and retains its
source witnesses. Missing required relations reject a structural mapping only
within this retained projection. Optional source gaps remain gaps. All behavioral
transfer conditions are unknown until their separate owners provide checks;
no current result claims equivalence, safe copying, edit permission or execution.

The real consumer `materializeSourceMotifLens` turns an owned checked mapping into
the existing task lens's exact-source facets, then retains named open transfer
conditions under the existing full-response budget. A cloned match object cannot
mint that authority. The source view owns immutable manifest snapshots, so later
caller metadata mutation cannot change the historical source facets.

Source views cap 64 nodes, 4096 relations and 8 MiB source bytes. Search bounds
entered states and candidate assignments, matches and cancellation independently;
relation scans are additional bounded work. Exhausting a budget yields partial
search. Full enumeration is scoped to the retained view and does not establish
global absence. Restart uses the same immutable view; durable cursors/spill are
not implemented. No performance or heap-size guarantee is claimed.

Authored unexecuted fixtures use a separate brute-force correspondence oracle,
both motifs, competing validators, wrong-object publication, reversed qualifiers,
missing closure, forged maps, cancellation and actual lens materialization.
Legacy retained adjacency projection, cross-view source/target correspondence,
provider-owned condition discharge, opaque continuations, migration campaigns,
binding adaptation and measured baseline/utility qualification remain open #1522
obligations. The source-only motif route remains independently inspectable.
