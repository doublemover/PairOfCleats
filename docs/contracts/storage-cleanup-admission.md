# Storage cleanup admission

Cleanup plan version 2 carries its exact entry/time limits and stop reason into
the reviewed identity. Earlier plans are rejected; create a fresh preview.
The existing cleanup owner and its CLI, clear-cache and native TUI consumers
retain complete producer qualification, original authority roots, file identities,
checksums and the same exclusive lease protocol. No new deletion category is added.

Planning applies one cooperative deadline across inventory, lease inspection,
authority capture and each file qualification. Cancellation/deadline checks
precede new phases and occur between native steps. A cancelled initial request
opens no reader. Incomplete inventory stops qualification. Protected/unqualified
roots do not cause pointless full-payload reads. A stopped preview is incomplete
and cannot authorize applying an otherwise qualified prefix.

Apply uses the plan's reviewed duration for one attempt, rechecks cancellation
before authority reads, exclusion entry, file verification and each unlink, and
reports later operations as skipped. A cancellation after one deletion retains
that exact positive outcome and preserves subsequent files. Already admitted
descriptors and exclusion metadata still settle through their original owners;
a deadline never releases them early or suppresses independent pending failures.
The receipt remains incomplete after cancellation, including an empty selection.

These are cooperative admission limits, not preemption of an operating-system
call already running. Verified contained readers retain their own signal and
close protocol. Declared entries are positive exact integers capped at 100,000;
duration is a positive safe integer. Each selected file remains subject to the
existing 8 MiB producer read ceiling. Unlink-confirmed logical bytes and estimated
allocation remain distinct from actual free-space reclamation, which stays unknown.

Six locally unrun controls exercise actual marked fixture roots, genuine command
probe records and original cleanup/reader owners. They cover pre-cancelled plan
and apply, time exhaustion during authority and file qualification, cancellation
between real unlinks, original reader close after cancellation, strict old-plan
rejection and ordinary positive deletion. Fixture removal verifies its physical
root and unique disposable marker. Existing lease, authority, replacement,
resource-observation and saved-evidence negatives remain unchanged.
