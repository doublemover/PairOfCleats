# Semantic JSON byte admission

`canonicalSemanticJson` accepts an optional `maxBytes` allowance. Its bounded path produces the same canonical JSON representation using an explicit traversal stack. It charges UTF8 JSON bytes, including object keys, punctuation, escaping, surrogate pairs and lone surrogates, before allocating encoded leaves. Oversized array lengths fail their minimum representation size before property enumeration. Own data descriptors, plain objects, dense arrays, finite numbers and cycle checks retain the existing JSON contract. Optional cancellation checks run during traversal and long string inspection.

`semanticHash` accepts the same optional `maxBytes` and `check` controls for its canonical input, preserving the existing domain separator and digest. Its ordinary two-argument path is unchanged. The source-linked evidence writer and retained detail reader use their existing report/read byte allowance for identity verification, so admitted deeply nested opaque metadata no longer returns to recursive encoding at those boundaries. Report finalization hashes its already admitted encoding. The existing durable evidence owner and compact public provider projection remain the storage/response owners; this adds no raw-report public field or independent query allowance.

The immutable evidence owner applies its existing one MiB default, or its existing caller-supplied allowance, before constructing a byte buffer or writing/registering a sidecar. Its typed budget error stays `ERR_SEMANTIC_EVIDENCE_BUDGET`. The retained definition lane uses that same owner to capture responses and charge the complete eventual sidecar envelope before retaining an observation or requesting the next occurrence. A budget failure publishes no binding partition and does not mark the document completed.

The structured LSP collector bounds incoming options/parameters by its existing `maxBytes` allowance and bounds raw responses, failed observations and projected envelopes by the remaining retained allowance. Oversized acquisition options fail before request reservation. Cached observations remain available without a second retained byte charge. Its existing `output_budget` partial outcome and observation/fact/item quotas remain authoritative. Freezing owned observations uses an explicit stack.

These are bounds on encoded data and retained snapshots made by these consumers. They do not bound caller-owned input allocation, Proxy hooks or engine property-enumeration internals. The definition session still captures its complete target selection and retains all admitted observations before publication; aggregate selection/session memory, other downstream hashes not using the bounded option, transport buffers and durable resumable streaming remain separate work. No public budget, new store, provider acquisition or source fallback is added. The unbounded canonical path and ordinary successful identities remain unchanged. Retained LSP producer identity advances for the changed admission outcomes.

Authored regressions compare canonical bytes at exact UTF8 boundaries, escaped and non-BMP strings, deep bounded input, passive rejection/cancellation, and actual evidence registration. Actual retained LSP session and structured collector cases cover sidecar metadata cost, no next-target acquisition after rejection, safe retry, whole-envelope fit, cached reuse and no request reservation/projection for oversized input. All are **UNVALIDATED**; no tests, syntax, lint, format, bootstrap, compiler/native/server/source execution or benchmarks were run.

Additional authored controls compare bounded hash bytes/digests, passive getters, exact UTF-8 allowance and interruption. A complete supplied report with 20000 nested metadata levels follows the existing durable writer/sink and internal detail reader, with exact metadata retained. Its sidecar exceeds the unchanged 64 KiB public page ceiling, so the public detail control requires a compact unavailable/budget state and normal cursor termination. This does not qualify arbitrary provider output, runtime parsers, public large-sidecar acquisition or full process-memory behavior.
