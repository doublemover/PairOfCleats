# Remaining bounded performance qualification

These explicit helpers require the already prepared Node 26/native runtime and
are outside ordinary test discovery. Run actual measurement capsules serially.
Each child has the existing 30-second deadline, bounded captured output, zero
retries and original native/resource owners. Supply a new absolute receipt
directory; successful generated work is reclaimed only by its captured UUID and
directory identity owner after validators close. Failures retain compact raw
stdout/stderr, original causes and any unconfirmed generated work.

- `tests/perf/qualification/sqlite-row-shapes.js`: actual canonical bundle build
  and three-round update work; six alternating paired trials over the declared
  source/cardinality shapes. It retains the existing 35% guard and 128 MiB size
  decision. Synthetic serializer output does not substitute for this work.
- `tests/perf/qualification/vfs-series.js`: all nine original UTF-8 cold/warm/hot
  steps with the original three shared roots and alternating order.
- `tests/perf/qualification/vfs-restart-misses.js`: actual persisted compaction
  and mixed regeneration, each with three fresh repetitions and byte parity.
- `tests/perf/qualification/map-builder.js`: actual map builder with 256 physical
  source files and canonical authored index facts, independently expected 17920
  members/edges, default-cap negatives and three fresh memory observations. This
  is not parser/compiler throughput qualification.
- `tests/perf/qualification/map-serialization.js`: six alternating paired trials
  for each synthetic 8 MiB/24 MiB minimum model shape under the unchanged 64 MiB
  admission limit. Each pair uses the original atomic publication owner and full
  parsed-output parity. Raw GC events and heap spaces describe observed collector
  work; they do not certify a heap peak. Lifetime RSS includes preparation and
  publication. Actual large-profile writer/warmup GC must be observed.

The map GC record is version 1. Unsupported or truncated observations retain
null phase counts and cannot qualify memory behavior. Small ordinary tests use
explicit named adapters only for recorder, error and lifecycle contracts; their
passing results do not qualify native operation or performance. All previous
aggregate timeouts and slower streaming observations remain historical evidence.
No helper grants a gain, sustained-workload, hardware or end-to-end claim merely
because a bounded capsule exits successfully.
