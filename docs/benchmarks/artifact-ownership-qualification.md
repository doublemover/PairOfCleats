# Artifact and ownership cost qualification

These explicit Windows-capable manual campaigns run after implementation, formatting and source freeze. They are outside ordinary discovery and never substitute for correctness fixtures. Each child uses the existing original subprocess owner, a30-second bound, zero retries and bounded stdout/stderr. Supply a new absolute destination beneath a task-owned `.tmp/` root.

`node tests/perf/qualification/artifact-costs.js <fresh-output>` runs stats, columnar, coverage, manifest, filter and repository-probe scenarios three times in counterbalanced order:18 fresh children. Receipts retain exact producer/consumer inputs, raw CPU/wall samples, separate instrumented work counts and separately sampled V8 JS allocations. Sampled bytes include collected objects; they are neither exact allocation counts, native allocations nor retained memory. Producer and consumer measurements have explicit scopes; current observations do not establish a historical speedup.

`node tests/perf/qualification/ownership-boundaries.js <fresh-output>` runs37 original manifest/filter/config failure controls with phase receipts. The tests use real descriptor owners, original captured close methods, publication fences and explicit close-only recovery. Manifest timestamps distinguish intentionally held read/close gates from post-release settlement. Cooperating publication entry bounds original lock retirement. A failed synchronous close remains unknown and is never retried through its numeric fd; fixture teardown retains its independent original test-owner cleanup. No receipt grants deletion, publication or recovery authority.

The regular runner additionally covers all falsey/frozen/source-plus-abort config failures, settled missing/malformed controls, and SQLite fallback enabled/disabled. All original assertions and negative cases remain. The filter cost scenario preserves the10,000-row corpus; original fresh-process cold-page and real SQLite/LMDB native-scaling tests remain independent correctness owners.

Physical POSIX literal-backslash versus nested-path names require a POSIX launch. Windows logical adapter controls do not qualify that case; no WSL, arbitrary symlink or elevated launch is required by these campaigns. Requested editor exclusions, optional backends and broad release qualification stay outside this acceptance. Historical author-workspace raw reports must be summarized into a committed source-bound receipt before issue closure.

`node tests/perf/qualification/remaining-p2-costs.js <fresh-output> [scenario ...]` runs three fresh serial repetitions per selected scenario. Defaults cover comparison-one, comparison-many, thread-cancellation, python-escaped and python-identifiers (15 children). A repaired cohort can be selected without repeating completed cohorts. Each comparison arm retains one actual six-query/two-model CLI and its complete registry lifetime. Thread cancellation uses original natural exits; saved Python sources use an actual CPython oracle, separate scanner allocation samples and real incremental refresh/rejected-producer admission. Partial lexical refresh is distinct from a parser-complete cache hit.

`node tests/perf/qualification/tree-sitter-cache-warm-compat.js <fresh-output>` runs three counterbalanced original/current cache-owner pairs on the same32 healthy source/native products. The committed original Git blob is verified and loaded only at its production module URL; the remaining producer and dependencies stay current. File admission, in-memory hits and persistent-memo hits have separate raw samples. Each owner writes its supported schema1/2 envelope. This is an owner comparison, with no historical whole-tree or speedup claim.

`node tests/perf/qualification/source-part-planning.js <fresh-output> [1 10 1000]` measures the actual canonical planner and an explicitly labeled valid-input sequential lookup comparator. Each selected shard count receives three fresh children. Independently authored canonical order/counts and physical backups remain exact; clean CPU/wall samples, property-read work and sampled/endpoint memory observations have separate scopes. The comparator does not reinstate the retired physical-path authority behavior.
