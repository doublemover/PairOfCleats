# CI artifact transfer

CI export writes version 4 bundles. Version 3 lacks a complete portable generation receipt and must be re-exported. Export resolves code and prose after child builds finish, holds the existing index lock and cache reader lease while packing, validates selected file artifacts and requested SQLite, and replaces the output directory only after its staged bundle is complete. The per-mode authority includes original publication/build-state provenance; mixed roots remain distinct. Unknown commit provenance stays unknown and cannot be stamped as the current checkout. Dirty provenance is recorded per mode.

Every regular bundle file has an exact size and SHA256 inventory entry. Links, special files, unsupported versions, missing/extra files and checksum failures are refused. Output and input paths may not overlap live cache authority. SQLite is read only from the corresponding mode generation, after checkpointing its WAL; configured external database paths are not portable generation sources. An omitted SQLite export remains explicitly omitted.

Restore validates the bundle before acquiring writer authority. It copies each mode into a fresh build root, verifies copied bytes, runs the ordinary strict validators, rebinds publication and independently verified zero-state path proofs, and uses the existing promotion owner to change all selected mode roots with one current.json commit. It never replaces selected generation files or custom database overrides. --force overrides commit policy only. Old generations remain with the existing retention owner; failed staged generations remain available through recovery diagnostics, including an ambiguous durability failure after pointer commit.

Authored controls cover inventory corruption, unsupported identity, overlap and early restore refusal. Full successful mixed-root restore, SQLite/zero-state, interrupted copy, injected promotion failure and durability qualification remain required before release acceptance. No validation or performance result is implied by this development change.
