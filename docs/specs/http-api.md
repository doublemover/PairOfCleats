[HTTP API server contract](../api/server.md). Runtime validators and schemas,
the router, shared error producer and trust-boundary owner linked there define
implemented behavior. Preserve their strict request and authorization contracts.

The [archived Phase 14.6/15.3 specification](../archived/http-api.md) preserves
this document's original proposal and test references. Its nested error envelope,
`results` wrapper and required text query are superseded; it is not an active
request/response authority. Snapshot/diff/federation semantics retain their linked
owners in the current guide. No runtime envelope or security default was changed
as part of this documentation reconciliation.
