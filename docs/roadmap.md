## Source-of-Truth Rules

1. `src/contracts/**`, validators, schemas, and generated contract artifacts are authoritative for wire shapes and required keys.
2. Current implementation plus tests are authoritative for whether roadmap work is done.
3. Focused specs under `docs/specs/**` are authoritative for detailed behavior when they match the code and validators.
4. This file is authoritative for status, sequencing, and roadmap references.
5. Archived docs under `docs/archived/**` are historical only, even when their original checklist boxes are unchecked.

Status labels:

- `done`: live code/tests/docs support the work.
- `in progress`: substantial implementation exists, but roadmap acceptance or release proof remains.
- `remaining`: intended work still needs implementation.
- `stale/superseded`: old plan content has been replaced or points at missing historical roadmap names.
- `blocked/unverifiable`: status depends on missing approvals, missing evidence, or validation not run in this audit.
